# :lock: Security Policy.

## Supported Versions

The following versions of Dynaserve CLI are actively supported with security updates.  
Users running unsupported versions are strongly encouraged to upgrade to a supported release.

| Version. | Support Status.                           |
| -------- | ----------------------------------------  |
| 3.0.0 >  | :green_circle: Currenlty Fully Supported. |
| 2.5.0+   | :orange_circle: Security Updates.         |
| < 1.0.0  | :red_circle: Unsupported.                 |

## Reporting a Vulnerability

If you discover a security vulnerability in Dynaserve CLI, please report it responsibly.  

- **Contact:** Email security@dynaserve.io with a detailed description of the issue.  
- **Response time:** Expect an acknowledgment within 48 hours.  
- **Resolution:** Confirmed vulnerabilities will be prioritized and fixed promptly.  
- **Disclosure:** After a fix is released, the issue may be publicly disclosed in the release notes.  

We appreciate responsible reporting and will credit contributors who help improve the security of Dynaserve CLI.
